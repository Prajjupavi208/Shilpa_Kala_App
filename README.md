# (Shilpa-Kala)

Shilpa kala is a premium artisan portfolio application designed for the handicraft makers of Karnataka. It allows artisans to capture high-quality product photos and automatically transform them into professional, branded portfolio cards ready for social media sharing.

## ✨ Features

- **Premium Artisan Studio**: Immersive CameraX implementation with dashed guide frames and focus brackets to help artisans capture perfectly centered products.
- **Luxury Branding Engine**: Automatically applies a sophisticated obsidian and gold aesthetic to captured photos, including:
  - Artisan Name and Village attribution.
  - Elegant product typography (Serif style).
  - Price tags with lightweight modern fonts.
  - "Handmade in Karnataka" heritage stamp.
- **Bilingual Support**: Full localization for **English** and **Kannada**, ensuring accessibility for local artisans.
- **Immersive Preview**: High-performance image viewer with pinch-to-zoom, pan gestures, and tactile reset controls.
- **Portfolio Gallery**: Organized storage for all branded creations with easy sharing via WhatsApp.
- **Modern UI/UX**: Built with Jetpack Compose following Material 3 guidelines, featuring obsidian gradients, gold ambient glows, and smooth transitions.

## 🛠 Tech Stack

- **Kotlin**: Primary programming language.
- **Jetpack Compose**: Modern toolkit for building native UI.
- **CameraX**: Robust camera integration for image capture.
- **Coil**: Image loading and caching.
- **Navigation Component**: In-app screen traversal.
- **Bitmap & Canvas API**: Custom branding and image processing.
- **EXIF Interface**: Automatic rotation correction for portrait/landscape shots.

## 🚀 Getting Started

### Prerequisites

- Android Studio Koala or newer.
- Android SDK 34+.
- An Android device (CameraX is best tested on physical hardware).

### Installation

1. Clone the repository.
2. Open the project in Android Studio.
3. Sync Project with Gradle Files.
4. Run the app on your device.
